# tactician

Chess puzzle service for the ilovepawn platform. Generates tactical puzzles from platform games (daily batch) and serves them to users via API.

## Attribution

This project vendors and adapts code from [Lichess's puzzle generator](https://github.com/ornicar/lichess-puzzler) by Thibault Duplessis (ornicar).
